# Publication note — V3.1

This is an AI-assisted research artifact. OpenAI Codex generated the code,
protocol drafts, exploratory analyses and internal verification. The separate
algorithms and same-system agent rewrite are computational checks, not an
independent human research team. No manuscript specialist has certified the
historical claims and no fresh reserved dataset has confirmed a candidate.

This snapshot contains six completed modern-edition families, all negative
under their declared screens. Nine mathematical families are frozen in the
research program. Later work may continue in separately recorded versions.
No divine-origin probability, universal absence claim or guarantee of a
future positive result is implied.

The 106 files of the verified V3.1 package are copied here unchanged. The
extra publication note, metadata and downloadable ZIP do not alter those
files. `MANIFEST.json` covers the package files; it intentionally excludes
itself and these publication additions. The archive SHA-256 is in
`PUBLICATION.json`.

The clean extracted package passed 27 tests, freshly downloaded and verified
32 pinned XML sources, and reproduced all 3,996 reference maxima of EXP-016
and EXP-017 with byte-identical primary outputs. Their separate-algorithm
checks cover all observed rules and four reference corpora per experiment;
1,994 references per experiment were not rescanned by a second algorithm.

The first V3 archive missed one test helper and failed a module import. V3.1
adds that original helper. This packaging correction changes no scoring
engine, rule, corpus or statistical protocol. Earlier negative trials,
failed executions and overlapping rule families remain counted.

Publication occurs after these exploratory outcomes. The GitHub commit time
is a public timestamp for this deposit, not retroactive preregistration of
the experiments. Local historical hashes alone are not external timestamps.

For reproduction commands and source attributions, see `README.md`. Its
statement that a local archive is not itself proof of publication describes
the archive at construction; the remote repository and immutable commit
provide the later publication evidence. The historical-manuscript branch
